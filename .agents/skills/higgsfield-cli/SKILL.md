# Higgsfield CLI

**Live schema truth.** Query live CLI introspection (`higgsfield model list`, `higgsfield model get <job_type> --json`, `higgsfield workflow list`, `higgsfield workflow get <name> --json`, `higgsfield voices list`, `higgsfield preset list`, `higgsfield account status`, `higgsfield workspace list`, and `higgsfield generate cost`) before relying on any static catalog or stale prose. Live schemas and CEL rules own valid parameters, enums, media limits, and mutual exclusions, overriding external skill claims whenever prose disagrees.

**Mandatory two-layer spend guard and `asset_locked` protection.** Route every paid campaign call and tracked reference upload through `python3 scripts/hf_guard.py` (`preflight`, `run`, `upload`, `status`) under [Budget Authority](../../../docs/video-workflow/shared/budget-authority.md). Every `hf_guard.py preflight` and `hf_guard.py run` call MUST pass BOTH mandatory `--round <R2|R3|R4|R4A|R4B|R5>` (`R4A` for Motion Pilot, `R4B` for Batch Draft Motion) AND mandatory `--round-cap <cumulative_cap>` (the cumulative Director-approved ceiling for that round, or `<round_spent + delta_cap>` on surgical re-rolls), alongside `--kind lookbook|still|video|audio|analysis`, `--variant A|B|C` for `R2` Lookbook options, and `--version <N>` for surgical Director-approved re-rolls (plus `hf_guard.py upload --campaign <dir> --file <path> --ref-id <id> --round R2`). Never bypass the guard via raw `higgsfield generate create`, `higgsfield generate workflow`, `higgsfield upload create`, `higgsfield product-photoshoot create`, `higgsfield soul-id create`, or MCP generation tools. `hf_guard.py` enforces both `Campaign cap` (`brief.md` `status: active`) and `--round-cap`, prevents duplicate spend across timeouts via `higgsfield generate list --json`, and refuses with `asset_locked` if the target asset is `LOCKED` in `shotlist.json`. There is **no `--force-unlock` CLI flag**—unlocking happens strictly via the Root Producer editing `shotlist.json` (`LOCKED` → `ITERATING`) after explicit Director instruction. Reserve direct CLI invocations strictly for free read-only discovery, status polling, and cost estimation; see [live workflow commands](references/live-workflows.md) for exact guarded calls.

**Lookbook, stills, and Soul identity (`R2`–`R3`).** Route mode-enhanced brand visuals through `hf_guard.py run --command product-photoshoot --model gpt_image_2 --kind lookbook --round R2 --round-cap <cumulative_cap>` across `product_shot`, `lifestyle_scene`, `closeup_product_with_person`, `hero_banner`, and `ad_creative_pack` (supports `--enhance-only`). Never pass `--count 3` with a single `--out` file (which silently discards variants B and C); instead issue separate per-variant calls with `--count 1`, distinct `--variant A` / `B` / `C`, contrasting prompts, and distinct `--out` files (`...-v1-A.png`, `-B.png`, `-C.png`). Inspect `higgsfield model list --image` (such as `gpt_image_2_6`) for general `R2` Lookbook worlds and `R3` `s01..sN` keyframes, and train recurring character likenesses via `hf_guard.py run --command soul-id --model soul_2 --kind lookbook --round R2 --round-cap <cumulative_cap>` (paired with `text2image_soul_v2` and free read-only `higgsfield soul-id list/get/wait`).

**Video model clusters, audio, and virality (`R3`–`R5`).** Choose `cinematic_studio_video_4_0` (workflow, `480p`/`720p`/`1080p`, up to 30 images and 50 total references across `image_references`, `video_references`, `audio_references`, `start_image`, and `end_image`, supporting `t2v`, `omni_reference`, `video_edit`, and `video_extension`) for multi-reference commercial cinematography (`R4A` Motion Pilot and `R4B` Batch Draft Motion at `480p`/`720p` → `R5` `1080p` Final Master). Choose `seedance_2_5` (model) when native `--draft true` (`R4A`/`R4B`) to `--draft_job_id` (`R5`) escalation or `4k` output in the live schema matters. Choose `marketing_studio_video` (or `marketing_studio_v2_video`) for ad and UGC flows (`default`, `web_product`, `from_storyboard`). For audio, pair `higgsfield voices list` with `elevenlabs_v4` or `seed_audio` (speech), `elevenlabs_music_v2_5` or `sonilo_music` (score), and `mirelo_text_to_audio` (SFX/foley). Use `brain_activity` (`--kind analysis`, taking `medias`) only as an optional advisory pacing read on an assembled cut.

**Honest Web Cinema Studio 4.0 boundaries.** Treat Web-only controls at `https://higgsfield.ai/cinema-studio`—specifically `Emotion Wheel`, `AI Cast`, and interactive visual lighting placement—as out-of-band human steps because they are absent from the live CLI schema. Likewise, opaque Cinema Studio 4.0 preset fields (`camera_model_id`, `camera_lens_id`, `camera_aperture_id`, `genre_id`, `era_id`, `pacing_id`, `light_id`) have no CLI `preset list` command: either leave them unset (`Auto`) and describe optics and lighting directly in the prompt, or reuse UUIDs stored using [`cinema-presets.example.json`](../../../docs/cinema-presets.example.json) after extracting them via `higgsfield generate get <job_id> --json`.
