# Higgsfield CLI

**Live schema truth.** Query live CLI introspection (`higgsfield model list`, `higgsfield model get <job_type> --json`, `higgsfield workflow list`, `higgsfield workflow get <name> --json`, `higgsfield voices list`, `higgsfield preset list`, `higgsfield account status`, and `higgsfield generate cost`) before relying on any static catalog or stale prose. Live schemas and CEL rules own valid parameters, enums, media limits, and mutual exclusions, overriding external skill claims whenever prose disagrees.

**Mandatory spend guard.** Route every paid campaign call and remote asset upload through `python3 scripts/hf_guard.py` (`preflight`, `run`, `upload`, `status`) under [Budget Authority](../../../docs/video-workflow/shared/budget-authority.md); never invoke raw `higgsfield generate create`, `higgsfield generate workflow`, `higgsfield upload create`, `higgsfield product-photoshoot create`, `higgsfield soul-id create`, or MCP generation tools that bypass the campaign budget envelope, `receipts.jsonl` lock, or timeout double-spend check against `higgsfield generate list --json`. Reserve direct CLI invocations strictly for free read-only discovery, status polling, and cost estimation, consulting [live workflow commands](references/live-workflows.md) when constructing exact guarded calls.

**Video model and workflow clusters.** Choose `cinematic_studio_video_4_0` (workflow, `480p`/`720p`/`1080p`, up to 30 images and 50 total references across `image_references`, `video_references`, `audio_references`, `start_image`, and `end_image`, supporting `t2v`, `omni_reference`, `video_edit`, and `video_extension`) for multi-reference commercial cinematography. Choose `seedance_2_5` (model) when native `--draft true` to `--draft_job_id` escalation or `4k` output in the live schema matters. Choose `marketing_studio_video` (or `marketing_studio_v2_video`) for ad and UGC flows (`default`, `web_product`, `from_storyboard`).

**Stills, Soul identity, audio, and virality.** Route mode-enhanced brand visuals through `hf_guard.py run --command product-photoshoot --model gpt_image_2` (`product_shot`, `lifestyle_scene`, `closeup_product_with_person`, `hero_banner`, `ad_creative_pack`; supports `--enhance-only`), train recurring character likenesses via `hf_guard.py run --command soul-id --model soul_2` (paired with `text2image_soul_v2` and read-only `higgsfield soul-id list/get/wait`), and inspect `higgsfield model list --image` for general keyframes. For audio, pair `higgsfield voices list` with `elevenlabs_v4` or `seed_audio` (speech), `elevenlabs_music_v2_5` or `sonilo_music` (score), and `mirelo_text_to_audio` (SFX/foley). Use `brain_activity` (`--kind analysis`, taking `medias`) only as an optional advisory virality read on an assembled rough cut.

**Honest Web Cinema Studio boundaries.** Treat Web-only controls at `https://higgsfield.ai/cinema-studio`—specifically `Emotion Wheel`, `AI Cast`, and interactive visual lighting placement—as out-of-band human steps because they are absent from the live CLI schema. Likewise, opaque Cinema Studio 4.0 preset fields (`camera_model_id`, `camera_lens_id`, `camera_aperture_id`, `genre_id`, `era_id`, `pacing_id`, `light_id`) have no CLI `preset list` command: either leave them unset (`Auto`) and describe optics and lighting directly in the prompt, or reuse UUIDs stored using [`cinema-presets.example.json`](../../../docs/cinema-presets.example.json) after extracting them via `higgsfield generate get <job_id> --json`.
