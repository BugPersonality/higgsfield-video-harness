# Higgsfield CLI

**Live schema truth.** Query `higgsfield model get <id> --json`, `workflow get <id> --json`, `voices list`, `preset list <type>`, `account status`, and `generate cost` before trusting static notes—live schemas and CEL rules own valid parameters and limits. Never pass private local file paths to `generate cost` before upload approval (local paths auto-upload).

**Guarded spend, Unlimited-first & model routing.** Always follow the priority ladder and 2026 image/video benchmarks in [model selection & Web Unlimited routing](references/model-selection.md): check `higgsfield.ai` **Unlimited (`0 cr.`)** via the built-in browser agent first (pausing for the Director to solve any login/CAPTCHA manually, then resuming the same browser session), fall back to economy CLI drafts (`gpt_image_2_6` `0.25 cr.`, `seedream_5_0_flash` `0.5 cr.`, `seedance_2_0_mini` `480p` `2.5 cr.`, `wan3_0` `480p` `5 cr.`), and reserve flagship `1080p` spends for approved `R5` cuts. Route every paid CLI job through `python3 scripts/hf_guard.py preflight` / `run` and tracked uploads (including downloaded browser outputs) through `hf_guard.py upload --round <R>` (0 cr.), enforcing the dual cap and lock rules in [Workflow](../../../docs/workflow.md#budget--lock-invariants) (see `hf_guard.py --help` and [live workflow gotchas](references/live-workflows.md)).

**Lookbook, spatial packs, stills, and Soul identity (`R2`–`R3`).** Use `hf_guard.py run --command product-photoshoot --model gpt_image_2 --kind lookbook` for mode-enhanced brand shots (`product_shot`, `lifestyle_scene`, `closeup_product_with_person`, `hero_banner`, `ad_creative_pack`), issuing separate `--count 1` calls per `--variant A|B|C` with distinct `--out` paths. Use `soul_location` / `cinematic_studio_soul_location` (`0.12 cr.`) for fast `R2` architectural lookbook exploration, then lock `2k`/`4k` masters and `R3` stills on `nano_banana_2_1`, `seedream_5_5`, `flux_3_image`, `kling_image_4_0`, or `gpt_image_2_6`. For multi-angle rooms, buildings, state relighting, outpainting, and isolated prop packs, route `nano_banana_2_shots` (1 ref → 3×3 sheet; slice via `make slice-grid`), `3d_jutsu_angles` (`2.5 cr.`, `2k`, `<= 10` refs), `nano_banana_2_relight`, `flux_kontext` (`1.5 cr.`, `<= 4` refs), `outpaint` / `flux_2_pro_outpaint`, `image_background_remover`, and workflow `image_decompose` (`2 cr.`, `== 1` ref) per [Locations, Buildings & Props](../video-consistency/references/locations-and-props.md). For recurring characters, `higgsfield soul-id` trains custom Soul IDs (`--soul-2` / `--soul-cinematic`) paired with `text2image_soul_v2` / `soul_cinematic` via `--custom_reference_id` (check `higgsfield soul-id --help`: current CLI lacks `soul-id cost`, so verify live cost support or train in Web if unquotable).

**Video, spatial rescue, audio, and virality (`R3`–`R5`).** Use `cinematic_studio_video_4_0` (`--workflow`, `--mode omni_reference`, up to 30 images / 50 refs, `480p`/`720p` → `1080p`) for multi-reference cinematography; `seedance_2_5` (model; `--mode omni_reference` / `video_extension`; `--draft true` → `--draft_job_id` escalation, up to `4k`); `kling_o3_image_reference` (`--multi_shots true --multi_prompt [...]`, `6.25–10 cr.`) for multi-cut cohesion inside one room; `kling4_0` (`reference-to-video`, `video-edit`, `<= 10` images + `kling_element_ids`) and `hf_mult_replace_object` / `hf_mult_replace_object_flash` (Genjutsu) to rescue a single drifted prop inside a locked clip; `marketing_studio_video` (`--workflow`) for UGC ads (check live `generate cost workflow` before quoting `--specific_mode from_storyboard`, whose live cost schema currently omits `storyboard_id`). For audio, pair `higgsfield voices list` (`--voice_id`, `--voice_type preset|element`) with `text2speech_v2` (`--variant elevenlabs|seed_speech|...`) or `seed_audio` for VO, `elevenlabs_v4` for multi-speaker `--dialogue`, `elevenlabs_music_v2_5` / `sonilo_music` for score, and `mirelo_text_to_audio` for SFX. Use `brain_activity` (`--kind analysis`) only as an optional advisory pacing read.

**Web Cinema Studio 4.0 boundaries.** `Emotion Wheel`, `AI Cast`, and interactive light placement exist only in the Web UI (`https://higgsfield.ai/cinema-studio`). Opaque preset UUIDs (`camera_model_id`, `camera_lens_id`, `light_id`, etc.) are absent from `preset list`: leave them unset (`Auto`) and describe optics/light in prose, or extract UUIDs from a web job via `higgsfield generate get <id> --json` into [`cinema-presets.example.json`](../../../docs/cinema-presets.example.json) shape.
