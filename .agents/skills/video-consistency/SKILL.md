# Video Consistency

Run consistency as a strict **round-by-round pipeline** backed by [Locations, Buildings & Props Runbook](references/locations-and-props.md) (for copy-ready templates, tool routing, `nano_banana_2_relight` 3D cube codes, and diagnostics) and mechanical `make campaign-check` validation:

1. **`R1B` — Triage & 4-Wall Map:** Run [Fast Plate Triage](references/locations-and-props.md#1-fast-plate-triage-if--then) to declare only needed plates (`1` Empty Master for single-angle sets; add **Reverse Wall** for OTS/reverse/mirrors; **State Plate** for day→night/weather/open-closed; **Scale Ref** for `WS`+`CU` props/buildings; **Tier 3 3D anchor** for 20+ shots or complex building flythroughs). Write an absolute **`N / E / S / W` Spatial Map**, per-shot `CAM` facing wall, eyeline, and mutable `PROP STATE` in `storyboard.md` and `shotlist.json`, prefixing IDs per set (`loc_<set>_*`, `prop_<item>_*`). Run `make campaign-check CAMPAIGN=<slug>`.
2. **`R2A` — Lock Empty Masters & Isolated Props (Unlimited-First):** Check `higgsfield.ai` Web `Unlimited` (`0 cr.`) first, else `soul_location` (`0.12 cr.`) → hero `2k`/`4k` lock (`seedream_5_5`, `nano_banana_2_1`, `flux_3_image`). Enforce **Empty Set Law** (zero people/clutter on location plates), **neutral `#808080` matte mid-gray + soft contact shadow + diffused `5000–5600K` light** on prop plates (kills *Lighting Bake-In*), **isolated talent portraits** without hero products, and `outpaint` / `flux_2_pro_outpaint` on mismatched client photo ratios. Lock winners (`status: "LOCKED"`, `approved_upload_id`).
3. **`R2B` — Expand Only Triggered Plates (`variants_requested: 1`):** Derive Reverse Walls (`3d_jutsu_angles` / `nano_banana_2_1`), angle sheets (`nano_banana_2_shots` → **`make slice-grid`** → upload winning clean tiles, never feed raw grids to video), lighting State Plates (`nano_banana_2_relight` / `flux_kontext`), or clean prop cutouts (`image_background_remover` / `image_decompose`) strictly from locked `R2A` Master UUIDs. *(Web vs. CLI: creating Cinema Studio Elements and `kling_element_ids` is Web UI only; CLI binds existing element IDs or uploaded `--image_references` UUIDs.)*
4. **`R3` — Stage `2k`/`4k` Keyframes (`3–5` Visible Refs):** Assemble set + cast + visible props in `2k`/`4k` stills using [Copy-Ready Templates](references/locations-and-props.md#3-copy-ready-templates) (camera facing wall, contact shadow plane, scale ratio, pigment isolation, explicit mirror reflections, and exterior↔interior **Threshold Anchors**). Prune all off-screen props/walls (**Visibility Pruning**). Lock & upload stills before any motion spend.
5. **`R4 / R5` — Delta Motion, Multi-Shot & Surgical Rescue (`2–4` Visible Refs):** Bind `1` locked `R3` `--start_image` + `1–2` highest-risk canonical **`R2`** UUIDs + optional `1` `--end_image`, pairing every `@ImageN` tag with its concrete noun and writing motion delta only. Never chain compressed screenshots without canonical `R2` UUIDs (**Zero Photocopy Cascade**). Respect hard CEL caps (`wan3_0` forbids `start_image`+`image_references`; `flux_3_video` forbids images+`video_references`). Use native multi-shot (`kling_o3_image_reference --multi_shots true` / `kling4_0` / `seedance_2_5`) for 2–4 cuts inside one room, `--mode video_extension` or physically traversable `start+end` with true 3D verbs ([camera grammar](../video-direction/references/prompt-patterns.md#camera-grammar-and-geometric-pairs)) for bridges, and `hf_mult_replace_object` / `hf_mult_replace_object_flash` (Genjutsu) or `kling4_0 --mode video-edit` to rescue a single drifted prop inside a locked take.
6. **Soul-2 Training (`R2`):** When recurring talent spans many angles/outfits, train a Soul ID (`higgsfield soul-id create --name <Name> --soul-2|--soul-cinematic --image ...`; 8–10 uniform evenly lit chest-up photos) and bind `--custom_reference_id` on `text2image_soul_v2` / `soul_cinematic` (`text2image_soul_v2` caps `--image_references` at 1 and forbids pairing `--style_id` with `--image_references`).

*Done when:* `make campaign-check` passes cleanly, every triggered `R2` Master / Reverse / State / Scale plate is `LOCKED` with verified UUIDs, every `R3` still (`3–5` refs) and `R4/R5` shot (`2–4` refs) binds only visible canonical anchors with explicit `@ImageN` roles, and `reviewer-agent` passes spatial, reflection, scale, and prop-state continuity across adjacent cuts.
