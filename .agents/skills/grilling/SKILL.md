# Grilling

Apply [Grilling](../../../docs/video-workflow/shared/grilling.md) standalone to stress-test a video brief, brand positioning, or comparative taste fork in front of you. Keep every technical mechanic—model choice, CLI flags, prompt syntax, UUID wiring, codecs, and FFmpeg filter chains—strictly off the Director's frontier, surfacing only viewer meaning, brand truth, comparative taste forks, spoken pronunciation, `Must not` taboos, and `Campaign cap` / retry boundaries. Continue authorized read-only grounding (reading `brands/` profiles and `taste.md`, inspecting reference photos, checking live Higgsfield schemas) while waiting for decisions that block the rest.

Once the **frontier** is empty, summarize the settled decisions (including rejected alternatives and why), labeled assumptions with `Reopen if` triggers, and residual risks, then wait for explicit confirmation before spending any credits or opening a production round—unless the user explicitly scoped this run as grill-only. If the Director confirms and wants to enter structured production, carry the settled meaning straight into [R0 Brief](../../../docs/video-workflow/rounds/r0-brief.md) (and initial `campaigns/<slug>/taste-log.md` guardrails for any settled taste rules) without re-asking them.
