# Grilling

Apply [Grilling](../../../docs/video-workflow/shared/grilling.md) standalone to stress-test the video brief, campaign intent, brand positioning, or creative fork in front of you. Keep every technical mechanic—model choice, CLI flags, prompt syntax, reference wiring, codecs, and FFmpeg filter chains—strictly off the requester's frontier, surfacing only viewer meaning, brand truth, taste forks, spoken pronunciation, `Must not` taboos, autonomy mode, and credit ceilings. Continue authorized read-only grounding (reading brand profiles, inspecting reference photos, checking live Higgsfield schemas) while waiting for decisions that block the rest.

Once the **frontier** is empty, summarize the settled decisions (including rejected alternatives and why), labeled assumptions with `Reopen if` triggers, and residual risks, then wait for explicit confirmation before spending any credits or launching a workflow phase—unless the user explicitly scoped this run as grill-only. If the user confirms and wants to enter structured production, carry the settled branches straight into [Intake](../../../docs/video-workflow/phases/intake.md) without re-asking them.
